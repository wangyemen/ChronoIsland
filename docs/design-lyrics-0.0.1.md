# 歌词功能 设计文档 v0.0.1

> 基于 [Lyricify Lyrics Helper](https://github.com/WXRIW/Lyricify-Lyrics-Helper)（**Apache-2.0**）+ Windows SMTC/GSMTC。
> 本文档是歌词功能的设计约定，主设计文档见 <design-0.0.1.md>。

---

## 1. 目标与非目标

### 目标
- 媒体播放时，灵动岛显示**逐行同步歌词**（当前行高亮）。
- **胶囊态**就能看到歌词，不必展开。
- 中文歌曲优先命中（QQ音乐 / 网易云 / 酷狗 / 汽水）。

### 非目标
- 不做歌词编辑、不做歌词社区贡献。
- 不打包 / 分发歌词数据（版权约束，见 §8）。
- 不做卡拉 OK 逐字高亮（v0.0.1 只做逐行；逐字能力库已具备，留待后续）。

## 3. 数据来源与轮转策略

### 3.1 来源清单（按优先级）

| # | 来源 | 歌词能力 | 凭据 |
| --- | --- | --- | --- |
| 1 | **QQ音乐** | 歌词 + 翻译 | **无需** |
| 2 | **网易云** | LRC / YRC 逐字 | **无需** |
| 3 | **酷狗** | KRC 逐字 | **无需** |
| 4 | **汽水音乐** | 歌词 | **无需** |
| 5 | **LRCLIB** | 同步 / 纯文本 | **无需** |
| — | Apple Music | TTML | 需 Media User Token（可选） |
| — | Spotify | 逐字 | 需 `sp_dc` Cookie（可选） |

v0.0.1 只启用前 5 个**无需凭据**的源。Apple / Spotify 作为后续可选项，由用户自填凭据后启用。

### 3.2 轮转 + 配额（防止单源请求过密）

**核心规则：每个源连续请求 N 次后，强制切换到下一个源，循环轮转。**

```
QQ音乐 ×3 → 网易云 ×3 → 酷狗 ×3 → 汽水 ×3 → LRCLIB ×3 → 回到 QQ音乐 …
                ↑ 任一步成功即停止并缓存
```

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 每源配额 | 3 次 | 达到配额即换下一个源，不论成败 |
| 单源冷却 | 60 s | 某源返回限流 / 错误 → 标记冷却，冷却期内跳过 |
| 全局重试上限 | 15 次 | 超过则本次放弃，等下一首歌 |
| 请求间隔 | ≥ 800 ms | 相邻两次请求最小间隔 |
| 曲目切换 | 重置配额 | 换歌时重新从 QQ音乐开始 |

**为什么这样设计**：这几个源都是逆向 / 公共服务，请求过密会被限流或封 IP。
轮转把压力均摊到 5 个源上，单源压力降到 1/5；配额机制保证不会死磕一个已失效的源。

### 3.3 缓存（必须）

- Key：`{artist}|{title}`（小写、去空格、清洗后）
- 位置：`%LOCALAPPDATA%\ChronoIsland\lyrics\`
- 内容：解析后的歌词数据 + 命中来源 + 时间戳
- 有效期：30 天
- **命中缓存则完全不发起网络请求** —— 这是降低请求量的主要手段

## 4. 从 SMTC 获取曲目信息

现有 `MediaSnapshot`（<Sources/MediaSource.cs>）已提供全部所需字段，无需改造：

| Lyricify 需要 | 本项目提供 | 来源 |
| --- | --- | --- |
| `Title` | `MediaSnapshot.Title` | `MediaProperties.Title` |
| `Artist` | `MediaSnapshot.Artist` | `MediaProperties.Artist` |
| `Album` | `MediaSnapshot.Album` | `MediaProperties.AlbumTitle` |
| `DurationMs` | `(int)(EndTicks / 10000)` | GSMTC Timeline |

### 标题清洗（必要）

浏览器 / B站 / YouTube 的标题常带杂讯，直接影响匹配率：

```
"晴天 (Official Music Video) - 周杰伦"  →  "晴天" + 艺人 "周杰伦"
"稻香【高清MV】"                        →  "稻香"
```

清洗规则：去除 `(...) [...] 【...】`、去除 `- 艺人名` 后缀、去除 `MV/Live/官方` 等关键词。
清洗结果同时用于查询与缓存 Key。

### 匹配等级

先用 `MatchType.High`（严格），未命中再降级 `Medium`。
`Low` 不使用 —— 误匹配会显示完全错误的歌词，体验比不显示更糟。

## 5. 胶囊态布局（重点）

### 5.1 布局调整

当前胶囊态媒体卡是**单行**：`封面 + 标题 + 作者 + 波形`。

改为**两行**：

```
┌──────────────────────────────────────────┐
│  ♪  我好想你                        ⏸    │  ← 第 1 行：封面+标题+作者（上移）
│     苏打绿                               │  ← 作者（小字）
│  ──────────────────────────────────────  │
│     我好想你 你在哪里                     │  ← 第 2 行：歌词（当前行）
└──────────────────────────────────────────┘
```

- **标题 + 作者整体上移**，为下方歌词腾出空间。
- 歌词行放在胶囊下半部，单行显示，不换行。
- 胶囊高度维持 `36 px` 冻结值不变（几何基线不改），靠**内部两行紧凑排版**实现。

> 若实测 36px 放不下两行，则歌词行作为**可选开关**默认关闭，
> 由用户开启后胶囊临时增高（见 §10 开放问题）。

### 5.2 宽度自适应与自动滚动（关键规则）

按需求，歌词显示遵循**三段式**：

```
① 歌词文本宽度 ≤ 岛当前宽度
   → 直接完整显示，不滚动

② 歌词超出当前岛宽，但岛宽 < 上限（MaxWidth / 420）
   → 先把岛加宽，直到达到宽度上限
   → 加宽后若放得下 → 完整显示

③ 加宽到上限仍放不下
   → 启用自动滚动
```

| 参数 | 值 |
| --- | --- |
| 岛宽上限 | `IslandMetrics.MaxWidth`（默认 420，设置可调） |
| 测量方式 | 离屏 `Measure` 文本实际宽度（与卡片高度实测同源） |
| 滚动速度 | 使整句在本行停留时长内滚动完一轮 |
| 滚动方向 | 从右向左；RTL 文本反向 |
| 滚动暂停 | 鼠标悬浮时暂停滚动，便于阅读 |
| 收尾 | 滚动到尾部后停留 1.2 s，再从头开始或由下句替换 |

**优先级：能不滚就不滚。** 滚动是最后手段，只在真的放不下时才启用。

## 6. 展开态（详情卡）

展开卡在现有媒体卡（封面 / 进度条 / 时间 / 控制按钮）基础上**增加歌词区**：

- 显示**当前行 + 前后各 1~2 行**上下文（共 3~5 行）
- 当前行：高亮 + 加粗；上下文：次级色淡化
- 切换行时用现有 `Spring.Float` 平滑滚动，**不每帧重绘**
- 翻译行（`SubLine`）以更小字号显示在原文下方，可在设置关闭

## 7. 时间轴

| 项 | 处理 |
| --- | --- |
| 时间单位 | 库给出 `int` 毫秒；SMTC 进度是 ticks → 统一换算 ms |
| 当前行定位 | 按 `StartTime` 二分查找（O(log n)） |
| 轮询间隔 | 200 ms（不每帧查询） |
| 插值 | 两次轮询之间按时间线性插值，保证高亮切换平滑 |
| 偏移补偿 | 设置项「歌词偏移 ±3 s」，用户微调 |
| 纯音乐 | 无歌词时不显示歌词区，不留空白 |

## 8. 风险与边界

| 风险 | 应对 |
| --- | --- |
| **版权** | 歌词有版权，属 UGC 数据。**仅运行时展示 + 本地缓存，绝不打包分发歌词数据** |
| 接口失效 | QQ/网易/酷狗为逆向接口 → 多源轮转 + 本地缓存，单源失效自动降级 |
| 限流封禁 | 轮转配额 + 请求间隔 + 缓存优先（缓存命中不发请求） |
| 误匹配 | 只用 High / Medium，不用 Low |
| 无歌词 | 优雅降级：隐藏歌词区，胶囊回到单行，不留空白 |
| 版本早期 | 库为 0.2.0 → 所有调用收敛在 `LyricsProvider` 一层，便于替换 |

## 9. 实施阶段

| 阶段 | 任务 | 验收标准 |
| --- | --- | --- |
| **1 地基** | 引入 NuGet 包；写 `LyricsProvider`（轮转+缓存）；命令行诊断 `lyrics` | 命令行能打印真实歌词（中文歌） |
| **2 胶囊** | 胶囊态两行布局；歌词行；宽度自适应 + 自动滚动 | 胶囊显示当前行歌词，长句自动滚 |
| **3 展开卡** | 详情卡歌词区（上下文行 + 高亮 + 弹簧滚动） | 展开后 3~5 行歌词，当前行高亮 |
| **4 打磨** | 偏移设置；翻译开关；纯音乐降级；标题清洗 | 设置项生效，异常场景不空白 |
